Mediago Analytics Adapter Test Page

This page tests the mediagoAnalyticsAdapter integration with Prebid.js.

It will capture and display all analytics data sent to the analytics endpoint.

Instructions:
  1. Configure the analytics settings below (or use defaults)
  2. Click "Initialize Prebid & Analytics" to set up Prebid.js
  3. Click "Run Auction" to start a test auction with multiple testBidder bids
  4. View the analytics data in the "Analytics Requests" section below
  5. Check the browser console for detailed logs

Note: This test uses multiple testBidder bids per ad unit to simulate a real auction scenario with multiple bidders competing. Ad Unit 1 has 3 bids, Ad Unit 2 has 2 bids.
